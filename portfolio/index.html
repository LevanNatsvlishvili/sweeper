Build notes

Free-play on a seeded PRNG, not a scripted board. A headless verifyRun() simulates a competent player at dev boot and asserts every seed is completable — goal reached, never dead-ended, board settled after every move.

  • Pure-data engine: matcher, board, and resolve() are unit-tested with zero Pixi imports
  • One resolve() pipeline replayed by the director — clone, animate, applyStep
  • Single-file Vite output, zero runtime network requests, MRAID viewability + pause/resume
  • Variant system: Classic stars + 800 goal; Cascade stripes, 1400 goal, JACKPOT + coin rain
  • Procedural PIXI.Graphics candies — no image assets, colourblind-safe shape + colour pairs
